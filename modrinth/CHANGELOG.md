# HolySwap 1.0.0 — первый релиз

## Added
- Циклический свап в оффхенд по категориям предметов: обычные талисманы, талисманы+ (по «+» в имени), сферы (по имени), обычные тотемы (по типу предмета)
- Экран-селектор предметов с группировкой по категориям; выбор сохраняется в config/holyswap.json
- Экран «Клавиши»: назначение любых клавиш прямо в игре, без ванильного меню управления
- Общие клавиши: несколько категорий на одной кнопке листают категории по кругу; предмет в руке не заменяется однородным
- Предмет в оффхенде отображается в селекторе и учитывается в цикле
- Подсказки в чате: что легло в оффхенд, из какой категории; предупреждение, если предмет в руке не выбран в селекторе

## Notes
- Клиентский мод, Fabric Loader 0.16+, Fabric API, Minecraft 1.21.4, Java 21
- Свап использует стандартный пакет клика по слоту (как ванильная клавиша F)
