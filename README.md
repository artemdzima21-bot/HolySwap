# HolySwap

Клиентский мод Minecraft: свап предмета во вторую руку (offhand) одной кнопкой.
Один клик — тот же пакет, что и ванильная клавиша F. **Не чит.**

Страница мода: Modrinth, проект `holyswap` (Fabric / Quilt / Forge / NeoForge, MC 1.16.5–1.21.11).

## Структура репозитория

Исходники каждой версии — отдельный Gradle-проект: заходим в папку и `gradle build`.

- **[fabric/](fabric/)** — 29 версий, MC 1.16.5–1.21.11 (эти же jar работают на Quilt)
- **[forge/](forge/)** — 27 версий, MC 1.16.5–1.21.11 (у Forge нет 1.17.0 и 1.21.2)
- **[neoforge/](neoforge/)** — 17 версий, MC 1.20.2–1.21.11 (включая 1.21.2, которого у Forge нет)

## Версии по лоадерам

| Лоадер | Версии MC | Папка |
|---|---|---|
| Fabric / Quilt | 1.16.5, 1.17–1.21.11 (29 шт.) | `fabric/holyswap-<версия>` |
| Forge | 1.16.5–1.21.11 без 1.17.0 и 1.21.2 (27 шт.) | `forge/holyswap-forge-<версия>` |
| NeoForge | 1.20.2–1.21.11 (17 шт.) | `neoforge/holyswap-neoforge-<версия>` |

## Возможности

- G — цикл талисманов, R — сфер, V — талисманов+, B — тотемов (клавиши настраиваются в игре)
- H — экран-селектор: клик по предмету добавляет/убирает его из цикла
- Общая клавиша на несколько категорий = цикл по категориям
- Конфиг на каждую версию Minecraft: `config/holyswap-<версия>.json`
- RU/EN локализация

## Сборка

В папке нужной версии:
```
gradle build
```
Готовый jar: `build/libs/`.
