# HolySwap

Клиентский мод Minecraft: свап предмета во вторую руку (offhand) одной кнопкой.
Один клик — тот же пакет, что и ванильная клавиша F. **Не чит.**

## Возможности
- G — цикл талисманов, R — сфер, V — талисманов+, B — тотемов (клавиши настраиваются в игре)
- H — экран-селектор: клик по предмету добавляет/убирает его из цикла
- Общая клавиша на несколько категорий = цикл по категориям
- Конфиг на каждую версию Minecraft: `config/holyswap-<версия>.json`
- RU/EN локализация

## Сборка
```
gradle build
```
Готовый jar: `build/libs/`.
